# Urban Waste Collection: Support Resources

This directory contains some support code for the Urban Waste
Collection problem. In particular:

- `waste_collection_instance_generator.py` is a utility to generate new
  instances. It requires `python3`.
- `waste_collection_instance_validation.py` is a utility to validate
  instances. It requires `python3`.
- `waste_collection.py` is a model for the
  [roar-net-api-py](https://github.com/roar-net/roar-net-api-py)
  python library to solve the problem.
