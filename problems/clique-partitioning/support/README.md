# Clique-Partitioning Problem: Support Resources

This directory contains some support code for the Clique-Partitioning
problem. In particular:

- `clique_partitioning.py` is a model for the
  [roar-net-api-py](https://github.com/roar-net/roar-net-api-py)
  python library to solve the problem.
